## 激活：Sign Up 而非登录，全程美国 IP

激活码官方说 1 个工作日内发到邮箱，实际有人等了 **26 小时**，也有人几分钟就收到。预付费套餐购买后 **90 天内必须激活**，别拖。

激活前先注册 RedPocket 官网账号。注意是点 **Sign Up 注册**，不是登录；激活邮件里 `redpocket.com/activate` 的链接进去后也要先有账号。用 Gmail 邮箱 + 密码注册即可，不建议用 Google 快速登录（社区两种说法冲突，保险起见走邮箱密码）。注册时也用干净的美国出口 IP，别连续快速点击、别反复提交。

激活全程：电脑浏览器无痕窗口、全局代理、开 TUN，先用 ip111.cn 确认出口是美国——无痕窗口可能不走代理，这一步别省。

几个关键填写项：

- **网络选 GSMA（AT&T）**，只有 GSMA 支持中国大陆漫游。
- **IMEI 填最终要用的那台手机的 IMEI**。多 IMEI 机型填 IMEI 2（拨号 `*#06#` 查看）。不要乱填：有人填随机 IMEI 也拿到了二维码，但装上后没信号、线路变 Suspended。IMEI 不能在黑名单里。
- **service ZIP** 影响分配哪个地区的号码，有人用洛杉矶 Northridge 的 91324。

如果最后一步报 `Activation Failed`，别马上重复提交。报错很笼统，不一定是 IP 问题。先登录 `redpocket.com/my-lines` 看线路是否已创建；再换浏览器或无痕窗口，确认代理开着、节点是美国，重试一次；还不行联系客服（页面右下角红色聊天按钮，电话 1-712-775-8777，太平洋时间 5 AM–9 PM）。

## 没有 eSIM 手机怎么办：白卡 + 读卡器 + NekokoLPA2

国行 iPhone、华为用户的核心痛点在这里。需要 eSIM 白卡 + 读卡器，用 **NekokoLPA2** 读写。淘宝搜“eSIM卡 eUICC 小白卡”，有 Android 手机只买小白卡即可，iPhone 和华为手机需要读卡器。

写卡流程：写卡手机连 Wi-Fi 挂美国节点 → 白卡接读卡器 → NekokoLPA2 选中白卡 → 右上角 `+` → 扫二维码或粘贴 `LPA:1$` 开头的链接 → 预览 → Download → 启用。

两个必须记住的点：

- **TAC 保持默认值 `35383741`**。TAC 是写卡时告诉服务器的设备信息，和激活页填的 IMEI 不是一回事。
- **二维码只能用一次**。写入成功后不要从手机里删除该配置文件，删了无法重新安装。下载失败别连续重试，最坏情况联系客服，核对邮箱和套餐信息后有人拿到过重发的二维码。

装卡后设置：RedPocket 线路**开数据漫游、关蜂窝数据**；默认数据线路选本地卡；**关闭“允许蜂窝数据切换”**，避免 100MB 被后台吃掉。

## 谁不该买这张卡

说清楚不适合的场景，比一味推荐更有用：

- **想当日常流量卡的人**：200MB 国内 + 100MB 漫游，拍几张照片就没了。
- **不愿意折腾网络环境的人**：激活、写卡、首次拉起 Wi-Fi Calling 都要美国 IP，节点还得支持 UDP。
- **对号码信誉要求极高的人**：号码可能是回收号，被占用的号码在部分服务上收不到验证码。
- **完全不能接受风险的人**：官方不支持中国大陆购买激活，所有环节都是社区变通，随时可能被收紧；客服也可能因你人在国内而拒绝处理部分请求。
